# CultureTechLens Citation Guide

This guide explains how to cite CultureTechLens research and how CTL records sources.

## Cite the specific research

Whenever possible, cite the individual CTL research page, report, dataset, or repository record that supports the claim.

### Website research

**CultureTechLens. “Research Title.” CultureTechLens, publication date. URL.**

### Repository research

**CultureTechLens. “Research Title.” CultureTechLens Research Repository, version or publication date. GitHub URL.**

Where useful, include the specific file path and commit or release identifier.

## Source citations

CTL source records should contain, when available:

- author or organization;
- title;
- publication or creation date;
- publication, collection, or repository;
- URL or archival identifier;
- access date;
- source type;
- notes about relevance or provenance.

## Citation principle

A citation should do more than point to a homepage. It should help a reader locate the evidence behind a claim.

## Version-specific citation

For research that changes over time, identify the version or commit when reproducibility requires an exact historical record.

Example:

**CultureTechLens. “Research Title.” Version 1.0, September 2026. CultureTechLens Research Repository. GitHub.**
