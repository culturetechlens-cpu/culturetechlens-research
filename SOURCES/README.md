# Source Register

The source register provides a machine-readable index of research sources used by CultureTechLens.

## Recommended fields

The CSV structure includes:

- `source_id` — stable internal identifier;
- `title` — source title;
- `author_or_org` — author or responsible organization;
- `publication_date` — publication or creation date when known;
- `access_date` — date CTL accessed the source;
- `source_type` — primary, institutional, scholarly, journalism, interview, secondary, etc.;
- `url` — source location;
- `evidence_summary` — concise description of relevant evidence;
- `status` — active, archived, unavailable, disputed, etc.;
- `notes` — additional context or limitations.

The register should not be treated as a substitute for the full research record.

See [METHODOLOGY.md](../METHODOLOGY.md) for source evaluation and evidence practices.
