# Data

This directory is intended for datasets and data documentation associated with CultureTechLens research.

Each dataset should document, when practical:

- purpose;
- scope;
- source;
- collection date;
- variables or fields;
- transformations;
- known limitations;
- licensing or usage restrictions;
- version;
- related research project.

## Data principle

A dataset is evidence or a research artifact, not automatically a conclusion. Interpretations drawn from data should remain distinguishable from the underlying data.

Sensitive, personally identifying, confidential, or restricted data should not be published merely for reproducibility. Legal, ethical, privacy, and licensing constraints apply.
