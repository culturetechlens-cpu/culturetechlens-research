# Research Projects

This directory is intended for project-level research records.

A project may include:

- research question;
- scope and definitions;
- claim register;
- source list;
- evidence notes;
- contextual notes;
- uncertainty and limitations;
- findings or analysis;
- citations;
- publication/version information.

## Suggested project structure

```text
RESEARCH/projects/
└── project-name/
    ├── README.md
    ├── claims.md
    ├── sources.csv
    ├── evidence.md
    └── CHANGELOG.md
```

Not every project requires every file. The structure should match the research question and available evidence.
